  Two Distinct Problem Categories

  Category 1: LLM Synthesis/Completeness (E2, E3, E4, E5, M3, M5-partial, H7-partial)
  The agent finds and reads the right docs. The data is in the tool results. The LLM just doesn't include it all. It tends to:
  - Answer the "headline" and skip supporting details
  - Scope narrowly to the exact words in the question (E4: "brand colors" → skips typography)
  - Produce terse answers when the question seems simple (E3: 2-line answer for an "easy" question)
  - Skip numbers/percentages in favor of qualitative descriptions (M3)

  Category 2: Planning/Retrieval (M5, H3, H4, H7-partial)
  The agent doesn't consult all required source files:
  - M5: Never opened Vendor Contracts Summary (adjacent but not obviously "compliance")
  - H3: search_drive for "Monarch" didn't surface Win-Loss Analysis; agent didn't just browse the folder
  - H4: Never opened Situation Overview doc alongside the spreadsheet
  - H7: FY2025 Budget spreadsheet is genuinely broken — openpyxl returns 0 rows/0 cols for a 23KB Google Sheets file exported to xlsx. This is a tool bug.

  The FY2025 Budget Bug

  This is a real infrastructure issue. The _handle_get_spreadsheet_overview uses openpyxl.load_workbook(data_only=True) which reads cached cell values. Google Sheets exported to xlsx via
   the Drive API may have no cached values if the spreadsheet uses formulas — openpyxl sees empty cells. This would also explain why H3's "Weighted Value" column was empty in the        
  pipeline tracker (formula cells with no cached values). This bug silently makes some spreadsheets unreadable.

  Evaluator Strictness

  The evaluator is actually slightly too strict in a few places:
  - E4: Flagged CMYK values and logo rules as "hallucinated" when they're in the source doc — the evaluator compares against expected answer only, not source docs
  - H4: Flagged "Municipal Bond Authority" as hallucinated when it's literally in row 14 of the spreadsheet
  - But the score thresholds (90+ pass, 60-89 partial, <60 fail) seem reasonable. The scores themselves are fair given what's missing.
